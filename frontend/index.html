Platform Security & Policies ENFORCED
🔒 Environment Separation

Strict isolation enforced: live API credentials cannot access test endpoints, and test credentials cannot access production resources.

🛡️ Cryptographic Key Hashes

API keys are hashed with salted PBKDF2/SHA256. Raw secrets are shown only once upon generation or rotation and are never retained at rest.

⚡ Ingestion Rate Limiting

Default policy enforces 120 requests/minute per connected application via Redis sliding-window counters with fail-closed security.

🔐 Payload Encryption

Inbound and historical payloads are protected at rest with AES-256 MultiFernet envelope encryption with key-rotation audit support.
